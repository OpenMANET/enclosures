# Compact OpenMANET Mesh Radio Build

## Overview

This project is a compact radio-style mesh build designed around a 3D printed enclosure and internally mounted electronics. The enclosure is intended to keep the build clean, compact and practical, with externally mounted antennas and room for the required power and radio components.

Several versions and layout options are included in the full project repository. These include different enclosure versions, component layouts, antenna mounting options and internal build approaches.

Full repository:
https://github.com/ties1887/Mesh-radio-Halow-LoRa
